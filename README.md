# Система управления учебной деятельностью кафедры

## Описание
Десктопное приложение для автоматизации учебного процесса кафедры вуза. 
Система предоставляет функциональность для управления студентами, преподавателями, 
учебными планами, расписанием и успеваемостью.

## Функциональность

### Ролевая модель:
- **Администратор** - управление пользователями, кафедрами, резервное копирование
- **Сотрудник кафедры** - управление студентами, преподавателями, учебными планами, расписанием
- **Преподаватель** - просмотр расписания, управление оценками, отчеты по нагрузке
- **Студент** - просмотр успеваемости, расписания, зачётной книжки

### Основные модули:
- Управление пользователями и ролями
- Учёт студентов и преподавателей
- Формирование учебных планов
- Составление расписания занятий
- Ведение успеваемости
- Генерация отчетов (ведомости, зачётные книжки, рейтинги)
- Резервное копирование БД

## Технологический стек

- **Backend**: Python 3.10+
- **GUI**: PyQt6
- **Database**: PostgreSQL 14+
- **Reporting**: python-docx, docxtpl
- **Authentication**: bcrypt
